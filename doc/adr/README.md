# Architecture Decisions

This directory contains accepted Architecture Decision Records for
`mega-linter-plugin-dclint`.

## Current Decisions

### ADR-001: Pin the Reviewed DCLint 3.1.0 Integration

The plugin pins DCLint 3.1.0 rather than following an unversioned npm install.
The descriptor mirrors DCLint's upstream Compose filename contract, including
modern `compose.yml` forms, dotted overrides, and nested paths such as
`compose/docker-compose-service.yml`. Integration tests protect both file
selection and DCLint's actual pass/fail behavior.

See [ADR-001](ADR-001-pin-reviewed-dclint-3.1.0-integration.md).

### ADR-002: Publish Versioned DCLint Descriptor Release Assets

Normal consumers use versioned GitHub release assets rather than the mutable
`main` descriptor. Each release publishes the descriptor and a SHA-256 checksum
after validating the exact generated bytes through MegaLinter. The repository
has no historical release lineage, so the new workflow establishes `v0.1.0` as
the first release and uses `vX.Y.Z` thereafter.

See [ADR-002](ADR-002-publish-versioned-descriptor-release-assets.md).
